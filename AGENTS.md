# Codex Scope

Codex works on the backend only in this repository.

## Allowed work

- Create and modify files under `backend/`.
- Update backend-related documentation, tests, configuration, and root-level files when required for backend development.
- Work on the `backend` branch or on backend feature branches created from it.

## Frontend boundary

- Do not create, modify, move, or delete files under `frontend/`.
- Do not implement UI, styling, browser-side behavior, or other frontend features.
- If a request requires frontend changes, stop and explain that the work is outside this Codex workspace's scope.
- Backend API changes may document the contract that the frontend will consume, but must not implement the frontend integration.
